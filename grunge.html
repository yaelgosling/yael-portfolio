Project

GRUNGE

This project explores the grunge music movement.

We were asked to take information from Wikipedia and turn it into a booklet that reflected our own interpretation of the movement. I chose to focus on the connection between the music, the environment it grew out of, substance abuse, and how these all played a part in the movement’s eventual decline.

The final project includes a typographic booklet, an event poster, and a digital platform promoting a curated grunge event featuring live performances, talks, and an exhibition.

Challenges

  • It was my first time designing a multi-page website in Figma, so I had to learn how to work with different functions, videos, and text while making sure everything worked well in a web format.
  • Finding a way to create a consistent visual style across all three formats, while still allowing each one to have its own identity.
